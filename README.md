# Классификация текстов 20 Newsgroups: rec.autos / rec.motorcycles / misc.forsale

Исследовательский вопрос: **когда использование
биграмм помогает классификации текста?**

## Классы

- `rec.autos`
- `rec.motorcycles`
- `misc.forsale`

## Структура проекта

```
project/
├── README.md
├── requirements.txt
├── run_experiment.py          # запускает весь пайплайн одной командой
├── src/
│   ├── data.py                # загрузка и первичный анализ данных
│   ├── baseline.py            # TF-IDF + LinearSVC

│   └── eda.ipynb              # (опционально) первичный анализ данных

```

## Установка

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск основного эксперимента

```bash
python run_experiment.py
```

Скрипт последовательно:
1. Обучает baseline (TF-IDF униграммы + LinearSVC);
2. Прогоняет эксперимент 1 (униграммы vs уни+биграммы);
3. Печатает топ-биграммы по каждому классу (эксперимент 2);
4. Прогоняет эксперимент 3 (влияние параметра регуляризации `C`);
5. Прогоняет эксперимент 4 (эффект биграмм отдельно по каждому классу);
6. Строит confusion matrix, считает разбивку ошибок по парам классов;
7. **Автоматически формирует `results/RESULTS.md`** — готовый отчёт со всеми
   реальными числами (без ручного копирования).

Результаты (csv-таблицы, график confusion matrix, `RESULTS.md`) сохраняются
в папку `results/`. **`results/RESULTS.md` — основной файл с итоговыми
цифрами**, его не нужно заполнять руками, он пересоздаётся при каждом запуске.

Альтернативный подход на эмбеддингах запускается отдельно (требует
`sentence-transformers`, скачивает предобученную модель при первом запуске):

```bash
cd src
python alternative.py
```

## Результаты

Полная таблица с реальными числами по всем экспериментам — в
[`results/RESULTS.md`](results/RESULTS.md), он создаётся автоматически
командой `python run_experiment.py`. Там же — таблица самых частых пар
"истинный класс → предсказанный класс" (`results/confusion_pairs.csv`) и
эффект биграмм отдельно по каждому классу (`results/experiment_4_per_class.csv`).

### Confusion matrix и ошибки

График сохраняется в `results/confusion_matrix.png`. Основная путаница
ожидается между `rec.autos` и `rec.motorcycles` — оба класса делят общую
лексику про транспорт (двигатель, цена, пробег, детали). `misc.forsale`
может пересекаться с обоими классами на объявлениях о продаже машины/мотоцикла.

## Эксперименты (структура записи)

Для каждого значимого эксперимента фиксируется:

1. **Что изменили** — например, добавили биграммы (`ngram_range=(1,2)`).
2. **Зачем** — гипотеза: устойчивые словосочетания вроде *"for sale"*,
   *"blue book"*, *"front wheel"* специфичны для класса и не ловятся
   униграммами.
3. **Результат** — конкретное значение macro-F1 и размер словаря.
4. **Вывод** — интерпретация: помогло/не помогло и почему (жанровые маркеры
   в `misc.forsale` vs рост разреженности признакового пространства).

### Проведённые эксперименты

1. **Униграммы vs уни+биграммы** — прямое сравнение базового признакового
   пространства с расширенным.
2. **Топ-биграммы по классам** — интерпретация весов линейной модели,
   объяснение, почему конкретные биграммы полезны для конкретного класса.
3. **Влияние регуляризации (`C`) на эффект от биграмм** — проверка гипотезы,
   что расширение признакового пространства требует другой силы
   регуляризации, иначе прирост от биграмм может маскироваться переобучением
   или, наоборот, недообучением.
4. **Альтернативный подход (sentence embeddings)** — сравнение разреженных
   счётных признаков TF-IDF с плотными семантическими эмбеддингами.

## Выводы (шаблон для заполнения)

- **Baseline**: ...
- **Что попробовали**: униграммы vs биграммы, разные `C`, эмбеддинги.
- **Что улучшило/ухудшило результат**: ...
- **Какие ошибки делает модель**: путаница `rec.autos` ↔ `rec.motorcycles`,
  пограничные объявления о продаже транспорта.
- **Почему модель их делает**: общая лексика, короткие тексты объявлений,
  жанровая неоднозначность.
- **Что проверить следующим экспериментом**: char n-граммы, взвешивание
  классов (`class_weight='balanced'`), объединение TF-IDF и эмбеддингов,
  увеличение `min_df` для биграмм для снижения шума.
